# 🍳 Chef Claude

### Your ingredients. Your AI chef. Your next favorite meal.

Chef Claude is an AI-powered recipe generator that transforms the ingredients you have at home into creative recipe ideas using the **Google Gemini API**.

Instead of wondering what to cook, simply enter your available ingredients and let AI do the thinking!

## 🌐 Live Demo

Try Chef Claude here: **[Visit Chef Claude](https://msn-del.github.io/chef-claude/)**

## ✨ Features

- **Ingredient Management:** Add ingredients to your list before generating a recipe.
- **AI Recipe Generation:** Generate personalized recipes based on your available ingredients using Gemini AI.
- **Markdown Rendering:** Display generated recipes in a clean, readable format.
- **Simple Interface:** An intuitive and user-friendly experience.
- **Dynamic Content:** Get different recipe suggestions based on your ingredients.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React 19 | Building the user interface |
| JavaScript | Application logic |
| Vite | Development environment and build tool |
| Google Gemini API | AI-powered recipe generation |
| React Markdown | Rendering generated recipes |

## 🚀 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/msn-del/chef-claude.git
```

### 2. Navigate to the project directory

```bash
cd chef-claude
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
